Tagwright

A clean library, one album at a time.

Point Tagwright at a staging folder and a library folder. It turns freshly downloaded FLAC and MP3 albums into clean, tagged, loudness-analysed albums with lyrics — and keeps everything in one canonical layout.

Get Tagwright0.5.0

Self-hosted · Docker · free and open source (GPL-3.0)

The board

See what each album needs.

Every folder in staging becomes one card with its cover, artist, album, year, Discogs ID, dynamic range, lyrics and a pipeline progress bar. Box sets with disc subfolders stay together as one album.

Filter for Needs input, Incomplete or Fixed, and switch between cards and a compact, sortable list. Card colour tells you at a glance where an album stands.

The pipeline

One run does the boring parts.

Dynamic range with drcalc, ReplayGain with rsgain, AcoustID fingerprints with fpscan, tags and cover from the assigned Discogs release, lyrics from lrclib.net and file names in your layout — in that order.

The inspector shows each step as done or partial, which tracks lack it, and a live log while fixes run. Tags Tagwright writes are never read back as input, and a user-owned tag is never overwritten by automation.

And a few more things

◈

Assign the right release

Search Discogs and MusicBrainz, then assign the release. Tags owned by Discogs stay read-only in the editor.

♫

Lyrics, synced

Plain and time-synced LRC lyrics from LRCLIB, with an editor for the lines that need a hand.

◉

Loudness, measured

Dynamic range and ReplayGain (EBU R128) written as tags, so you know what you are listening to.

▣

A canonical library

Move to library places files in your chosen folder and filename layout, with the cover recreated.

✦

Your existing versions

The inspector shows other versions of the same Discogs master already in your library.

◇

One user, one tab

FastAPI and Next.js, no database server and no account. The decisions behind every behaviour are documented in the ADRs.

Install

Run it yourself.

  1. Pull the container image from ghcr.io and start it with Docker Compose.
  2. Point Tagwright at your staging folder and your music library folder.
  3. Open it in a browser tab. There is no account to create and no database to set up.

Full quick-start and configuration: in the README on GitHub. Python 3.14, GPL-3.0-or-later.
